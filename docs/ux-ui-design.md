# EazyAccount UX/UI Design

## Product Direction

EazyAccount เป็นแอปบัญชีแบบ voice-first สำหรับพ่อค้าแม่ค้ารายย่อย จุดหลักของ UX คือ "พูดให้เร็ว ตรวจให้ชัด แก้ให้ทัน" ผู้ใช้ควรเปิดแอปแล้วเห็นปุ่มไมค์ทันที โดยมีข้อมูลล่าสุดและยอดรวมให้มั่นใจว่าระบบบันทึกถูกต้อง

## Color System

| Token | Hex | Usage |
| --- | --- | --- |
| Primary Teal | `#0F766E` | ปุ่มหลัก, mic idle, active navigation |
| Soft Teal | `#E6F3F0` | พื้นหลังกล่อง voice control |
| Income Green | `#15803D` | รายรับ, ลูกศรรับเงิน |
| Expense Red | `#B42318` | รายจ่าย, สถานะกำลังฟัง/หยุด |
| Ink | `#1F2A24` | ข้อความหลัก, table header |
| Muted | `#69746B` | ข้อความรอง |
| Surface | `#FFFFFF` | card/list/table |
| Background | `#F7F6F0` | พื้นหลังหลักของแอป |
| Border | `#E4E0D4` | เส้นแบ่งและ card border |
| Amber Accent | `#F4B942` | สมัครสมาชิก/จุดขาย paid plan |

## Thai Font

ใช้ `Noto Sans Thai` เป็น font หลัก เพราะอ่านง่ายบนมือถือและเหมาะกับตัวเลขปนภาษาไทย มี fallback เป็น `Tahoma`, `Arial`, `Roboto` เพื่อให้ยังแสดงผลได้หากเครื่องไม่มีฟอนต์หลัก

## UX Flow

```text
เปิดแอป
  -> Home
  -> เลือก Push หรือ Auto
  -> กดปุ่มไมค์
  -> ระบบฟังเสียง
  -> AI speech + parsing แปลงเป็น รายการ/รายรับ/รายจ่าย
  -> แสดงในรายการล่าสุด
  -> ผู้ใช้กดดูรายละเอียด
  -> ตรวจตาราง
  -> ดูรายงาน วันนี้/สัปดาห์/เดือน
  -> ตั้งค่าภาษา สำรองข้อมูล หรือสมัครสมาชิก
```

## Interaction Notes

- ปุ่มไมค์ต้องใหญ่ที่สุดในหน้า Home เพื่อสื่อว่าเป็น primary action
- Push เหมาะกับ MVP เพราะผู้ใช้ควบคุมจังหวะพูดเองได้ง่าย
- Auto เป็น future-ready mode สำหรับการฟังต่อเนื่อง
- รายการล่าสุดช่วยลด anxiety หลังพูด เพราะผู้ใช้เห็นทันทีว่าระบบจับอะไรได้
- ตารางรายละเอียดแยก รายจ่าย/รายรับ ชัดเจน ลดความผิดพลาดก่อน export หรือ sync
